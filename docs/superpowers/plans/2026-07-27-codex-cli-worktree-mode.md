# Codex CLI Worktree Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add `codex -w/--worktree [name]` for local interactive sessions, creating an isolated Git worktree under `.codex/worktrees`, starting Codex there, and prompting to keep or remove it on exit.

**Architecture:** Keep app-server protocol unchanged. Put low-level Git worktree operations in `codex-git-utils`, prepare the interactive worktree inside `codex_tui::run_main` after local-vs-remote launch resolution and config load, and prompt for final cleanup in the CLI wrapper after the TUI exits and the terminal is restored.

**Tech Stack:** Rust, clap, Git CLI through existing `codex-git-utils` command helpers, serde/schemars config types, `just` test/fmt workflow.

```rust
pub fn prepare_worktree(
    source_cwd: &Path,
    options: WorktreePrepareOptions,
) -> Result<PreparedWorktree, GitToolingError> {
    let source_root = crate::operations::resolve_repository_root(source_cwd)?;
    let path = source_root.join(".codex").join("worktrees").join(&options.name);
    let branch = format!("worktree-{}", options.name);
    let base_ref = resolve_base_ref(&source_root, options.base_ref)?;

    if path.exists() {
        crate::operations::ensure_git_repository(&path)?;
        return Ok(PreparedWorktree {
            source_root,
            path,
            branch,
            base_ref,
            created: false,
            generated_name: options.generated_name,
        });
    }

    let args = vec![
        OsString::from("worktree"),
        OsString::from("add"),
        OsString::from("-b"),
        OsString::from(&branch),
        path.as_os_str().to_owned(),
        OsString::from(&base_ref),
    ];
    run_git_for_status(&source_root, args, /*env*/ None)?;

    Ok(PreparedWorktree {
        source_root,
        path,
        branch,
        base_ref,
        created: true,
        generated_name: options.generated_name,
    })
}

fn resolve_base_ref(source_root: &Path, base_ref: GitWorktreeBaseRef) -> Result<String, GitToolingError> {
    match base_ref {
        GitWorktreeBaseRef::Head => Ok("HEAD".to_string()),
        GitWorktreeBaseRef::Fresh => run_git_for_stdout(
            source_root,
            [OsString::from("rev-parse"), OsString::from("--verify"), OsString::from("origin/HEAD")],
            /*env*/ None,
        )
        .or_else(|_| Ok("HEAD".to_string())),
    }
}

pub fn inspect_worktree(prepared: &PreparedWorktree) -> Result<WorktreeStatus, GitToolingError> {
    let porcelain = run_git_for_stdout(
        &prepared.path,
        [OsString::from("status"), OsString::from("--porcelain")],
        /*env*/ None,
    )?;
    let has_untracked = porcelain.lines().any(|line| line.starts_with("??"));
    let has_tracked_changes = porcelain
        .lines()
        .any(|line| !line.starts_with("??") && !line.trim().is_empty());
    let commits_ahead = run_git_for_stdout(
        &prepared.path,
        [
            OsString::from("rev-list"),
            OsString::from("--count"),
            OsString::from(format!("{}..HEAD", prepared.base_ref)),
        ],
        /*env*/ None,
    )?
    .parse()
    .unwrap_or(0);

    Ok(WorktreeStatus {
        has_tracked_changes,
        has_untracked,
        commits_ahead,
    })
}
```

```rust
#[derive(Debug, Clone, PartialEq, Eq)]
pub(crate) struct WorktreeRequest {
    pub(crate) name: String,
    pub(crate) generated_name: bool,
}

impl WorktreeRequest {
    pub(crate) fn from_cli_value(value: Option<String>, seed: &str) -> Self {
        match value {
            Some(value) if value.trim().is_empty() => Self {
                name: generated_worktree_name(seed),
                generated_name: true,
            },
            Some(value) => Self {
                name: sanitize_worktree_name(&value),
                generated_name: false,
            },
            None => Self {
                name: generated_worktree_name(seed),
                generated_name: true,
            },
        }
    }
}

pub(crate) fn generated_worktree_name(seed: &str) -> String {
    format!("{}-{}", sanitize_worktree_name(seed), uuid::Uuid::new_v4().simple())
        .chars()
        .take(40)
        .collect()
}

fn sanitize_worktree_name(value: &str) -> String {
    let mut out = String::new();
    let mut last_dash = false;
    for ch in value.trim().to_ascii_lowercase().chars() {
        let next = if ch.is_ascii_alphanumeric() { ch } else { '-' };
        if next == '-' {
            if !last_dash && !out.is_empty() {
                out.push(next);
            }
            last_dash = true;
        } else {
            out.push(next);
            last_dash = false;
        }
    }
    out.trim_matches('-').to_string()
}
```

```rust
pub(crate) fn copy_worktree_includes(source_root: &Path, target_root: &Path) -> anyhow::Result<()> {
    let include = source_root.join(".worktreeinclude");
    if !include.exists() {
        return Ok(());
    }
    let contents = std::fs::read_to_string(include)?;
    for line in contents.lines() {
        let pattern = line.trim();
        if pattern.is_empty() || pattern.starts_with('#') {
            continue;
        }
        if pattern.contains("..") {
```
